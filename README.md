# School Data Cleaning Project

## Overview

This project demonstrates a complete data cleaning and preparation workflow using Python and Pandas on a school management dataset.

The objective is to transform raw data into a clean, consistent, and analysis-ready dataset that can be used for reporting, dashboard development, and database integration.

---

## Tools & Technologies

* Python
* Pandas
* NumPy
* Jupyter Notebook
* SQL Server

---

## Dataset Components

The dataset contains multiple educational entities including:

* Students
* Teachers
* Courses
* Classes
* Departments
* Student Assessments

---

## Data Cleaning Tasks

The following cleaning operations were performed:

* Handling missing values
* Standardizing categorical values
* Cleaning text fields
* Removing inconsistencies
* Creating derived columns
* Preparing SQL-compatible structures
* Data validation and quality checks
